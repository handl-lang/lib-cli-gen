# lib-cli-gen

Generated handl SDKs for installed CLIs — `git`, `docker`, `ffmpeg`,
`kubectl`, `aws`. For each tool, `hnl codegen cli` emits a port module
plus a `cli-c` adapter; this repo holds the specs and smoke tests, not
the generated code.

## Layout

| path | role |
| --- | --- |
| `specs/<tool>.clispec.yaml` | committed command-tree specs (probe-emitted or hand-authored) |
| `src/<tool>.test.hnl` | per-tool smoke tests — local-safe calls only (`git version`, `docker version --client`, …) |
| `generated/` | gitignored build artifact — regenerated by the gate |
| `pkg.hnl`, `scripts/hnl-gate.sh` | manifest (10 modules) + gate that re-emits specs first |
| `workflows/gate.yaml` | CI — shared `handl-gates` campaign |

## Contract

- `generated/` is never committed; `hnl-gate.sh` runs
  `hnl codegen cli specs/*.clispec.yaml` before gating (needs
  `HANDL_EXT_DIR` pointing at built `ext-*` cdylibs).
- Hand-tuned specs are marked `# hand-authored` / `# hand-tuned`.
- Runtime dep: `lib-cli` (`cli` port + `cli-c` backend), mapped in
  `.handl.toml`.

## Verification

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
# or: ./ci.sh (bupha entry where present)
```
